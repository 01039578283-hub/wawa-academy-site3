자료의 출처와 시험 목적을 확인하세요

유형을 실제 읽기 행동으로 바꾸세요

주제 문제라면 중심 주장과 예시의 관계, 내용 확인이라면 대상·시간·범위, 순서 문제라면 지시어와 연결을 살펴볼 수 있습니다. 유형마다 하나의 기계적인 공식으로 풀기보다 해당 글의 근거를 찾아 설명하세요.

정답 근거와 오답 이유를 함께 남기세요

정답 번호만 적지 말고 판단에 쓴 문장이나 문단 관계를 표시합니다. 선택지의 범위가 넓어진 것인지, 원인과 결과가 바뀐 것인지 비교하세요. 맞힌 문제도 추측했다면 확인 과제로 남깁니다.

정답 해설에 없는 자신의 추론이 있다면 글에서 근거를 찾아 보세요. 정답 번호를 외우기보다 어떤 문장 관계로 판단했는지 설명하고 불명확한 부분은 질문으로 남깁니다.

빈칸 판단에서는 글의 관계를 확인하세요

앞부분의 주장과 뒤의 예시가 어떤 관계인지 설명하고 빈칸에 필요한 의미를 정합니다. 같은 단어가 있는 선택지라는 이유만으로 고르지 마세요. 어려운 문장이 있다면 구조를 나눠 읽고 전체 흐름으로 다시 연결합니다.

분석 결과를 새 지문에서 검증하세요

새 지문에서도 같은 유형을 틀렸다면 필요한 어휘와 문장 구조를 다시 봅니다. 유형별 풀이 순서를 더 외우는 일보다 실제로 이해하지 못한 구간을 좁히세요.
